# 企业知识产权管理系统（IPMS）

面向企业知识产权部的全栈管理系统，覆盖**著作权、专利、数据知识产权、商标**四类资产的全生命周期管理，提供台账维护、可视化统计分析、规避设计与风险战略分析。

数据持久化保存在服务端 SQLite 数据库中，刷新页面或重启服务后数据依然存在，支持完整的增删改查。

---

## 一、功能特性

### 1. 企业基本信息管理
企业名称、统一社会信用代码、所属行业、企业类型（国企 / 民企 / 外企等）、注册地址、成立时间、注册资本、法定代表人、联系人、联系电话、邮箱、网址、知识产权管理部门与负责人、企业简介，全部支持在线编辑保存。

### 2. 知识产权全类型管理
| 大类 | 子类型 |
| --- | --- |
| 专利 | 发明专利、实用新型专利、外观设计专利 |
| 著作权 | 软件著作权、作品著作权 |
| 数据知识产权 | 数据资源登记、数据产品登记 |
| 商标 | 注册商标 |

每条知识产权包含三大板块信息：

- **基本信息**：名称、类型 / 子类型、申请号 / 登记号 / 注册号、申请日 / 登记日、申请人 / 权利人、发明人 / 设计人 / 作者 / 创作人、代理机构、分类号（IPC / 洛迦诺 / 尼斯 / 著作权分类）、技术领域或商品类别、归属部门、保护地域
- **法律状态**：当前状态（申请中、审查中、已授权 / 已登记 / 已注册、有效、维持中、质押、许可、诉讼中、年费滞纳、撤三风险、驳回、撤回、失效、终止）、状态变更记录（完整留痕并自动追加）、年费缴纳情况与下一年费截止日、保护期限起止日
- **具体保护范围**：权利要求书摘要 / 保护范围描述、外观设计视图与设计要点描述、商标核定使用的商品 / 服务类别、著作权作品内容描述、数据知识产权的数据范围与登记内容、地域保护范围、被保护的技术方案或数据要点、竞争对手参照专利族

表单字段标签随所选类型自动切换（如专利显示"发明人"，著作权显示"作者"），子类型随大类联动。

### 3. 统计分析与可视化
基于 ECharts 5.5 呈现：

- 各类知识产权数量与占比（环形图）
- 法律状态分布（环形图）
- 按年份的申请 / 授权趋势（柱线组合图）
- 专利类型分布、著作权类型分布、数据知识产权类型分布（饼图）
- 商标类别分布、技术领域分布（条形图）
- 归属部门分布、保护地域分布
- 到期提醒：年费逾期、年费待缴、商标续展、数据知识产权续展、专利保护期届满（支持 90 天 / 1 年 / 2 年 / 全部切换）
- 综合分析结论与布局能力评分（专利质量、外围布局、维度完整性、维持管理、地域布局、运营转化、创新持续性），并输出改进建议

### 4. 战略中心
系统依据台账数据自动推导战略条目，也支持手动增删改：

**规避设计战略**
围绕竞争对手专利族的规避设计、外围专利布局、防御性公开、挖掘与申报策略、标准必要专利（SEP）、软件类成果的"专利 + 软著"组合保护、数据资产入表布局、海外布局。

**风险战略**
年费维持风险（按 30 / 60 / 90 天分级预警）、年费滞纳导致权利终止、商标续展提醒、商标撤三风险（按注册满三年判定）、数据知识产权登记失效与续展、审查周期异常、发明专利提实审期限、FTO 自由实施与侵权预警、诉讼与权利稳定性、失效资产复盘、布局结构风险、商标类别缺口、数据合规与授权链。

每条战略条目包含风险等级、分类、分析内容、分条应对建议、责任人、完成时限与处置状态，点击标题展开详情。数据变更后可一键"重新生成智能建议"（手动条目保留）。

### 5. 界面
左侧导航管理后台风格（概览 / 企业信息 / 知识产权管理 / 统计分析 / 战略中心 / 系统设置），顶部显示企业名称与快捷新建入口；台账支持按类型、子类型、状态、部门、关键词组合筛选搜索；新建与编辑采用表单弹窗，详情采用右侧抽屉；统计页图表化呈现。

### 6. 内置演示数据
预置示例企业**衢州量智科技有限公司**及 29 条各类型知识产权（发明 6、实用新型 5、外观 3、软件著作权 5、作品著作权 2、商标 5、数据知识产权 3），含 27 条状态变更记录、23 条年费记录、25 条自动生成的战略建议，覆盖有效、审查中、申请中、质押、许可、年费滞纳、撤三风险、失效、驳回等全部典型状态，可直接查看统计与战略分析效果。

## 二、快速开始

### 环境要求
- Python 3.8 及以上（**无需安装任何第三方依赖**，仅使用标准库）
- 现代浏览器（Chrome / Edge / Firefox）

### 启动

```bash
# 方式一：命令行启动（默认端口 8770，可自定义）
python server.py
python server.py 9000          # 指定端口
python server.py 8770 --no-browser   # 不自动打开浏览器

# 方式二：Windows 双击 start.bat
```

首次启动会自动完成：
1. 创建 `data/ipms.db` 数据库与全部数据表
2. 写入内置演示数据
3. 依据演示数据自动生成战略建议
4. 自动打开浏览器访问 `http://127.0.0.1:8770/`

停止服务：在终端按 `Ctrl + C`。

### 冒烟测试（可选）

```bash
python server.py 8770 --no-browser   # 另开终端启动服务
python smoke_test.py                 # 验证全部接口，预期输出「通过 26 / 26」
```

## 四、数据模型

| 表 | 说明 |
| --- | --- |
| `company` | 企业基本信息（单条记录，id=1） |
| `assets` | 知识产权主表，含基本信息、法律状态、保护范围三组字段 |
| `status_logs` | 状态变更记录，随主表状态变化自动追加，支持手动维护 |
| `fee_records` | 年费 / 续展缴纳记录，保存时同步回填主表年费字段 |
| `strategies` | 战略条目，`source` 区分 `auto`（系统生成）与 `manual`（手动新增） |

外键均配置 `ON DELETE CASCADE`，删除知识产权时关联记录自动清理。

## 五、接口一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET / PUT | `/api/company` | 读取 / 保存企业信息 |
| GET | `/api/assets` | 台账列表，支持 `category` `sub_type` `status` `department` `region` `keyword` `sort` `page` 参数 |
| POST | `/api/assets` | 新建知识产权 |
| GET / PUT / DELETE | `/api/assets/<id>` | 读取 / 更新 / 删除单条（含状态与年费记录） |
| POST | `/api/assets/<id>/logs` | 追加状态变更记录（并同步主表状态） |
| POST | `/api/assets/<id>/fees` | 追加年费记录（并同步主表年费字段） |
| PUT / DELETE | `/api/fees/<id>` | 更新 / 删除年费记录 |
| DELETE | `/api/logs/<id>` | 删除状态变更记录 |
| GET | `/api/stats/overview` | 总量、有效率、风险数、类型 / 状态 / 部门 / 地域分布 |
| GET | `/api/stats/trend` | 按年份的申请量与授权量趋势 |
| GET | `/api/stats/expiry?days=365` | 年费、商标续展、数据登记、专利到期的到期清单 |
| GET | `/api/stats/distribution` | 专利 / 著作权 / 商标类别 / 数据 / 技术领域分布 |
| GET | `/api/stats/analysis` | 综合结论、布局评分与改进建议 |
| GET / POST | `/api/strategies` | 战略条目列表 / 新增 |
| PUT / DELETE | `/api/strategies/<id>` | 更新 / 删除战略条目 |
| POST | `/api/strategy/rebuild` | 依据当前数据重新生成智能建议 |
| GET | `/api/export` | 导出全量 JSON 备份 |
| POST | `/api/import` | 导入 JSON 备份（覆盖式） |
| POST | `/api/reset` | `mode=demo` 恢复演示数据 / `mode=empty` 清空数据 |
| GET | `/api/meta` | 枚举字典（类型、状态、部门、地域、风险等级）与服务端基准日 |

## 六、数据与备份

- 全部数据位于 `data/ipms.db`，采用 SQLite 单文件存储，可直接复制该文件完成迁移。
- 系统设置页提供「导出数据备份（JSON）」与「导入备份文件」，支持跨机器迁移。
- 「恢复内置演示数据」与「清空全部数据」用于快速回到初始状态，操作前有二次确认。
- `data/*.db` 已写入 `.gitignore`，不会进入版本库；克隆仓库后首次启动会自动重建演示数据。

## 七、到期与风险判定口径

| 事项 | 判定规则 |
| --- | --- |
| 年费预警 | 距下一年费截止日 30 天内为高、60 天内为中、90 天内为低；已过应缴日未缴为逾期高 |
| 年费滞纳 | 状态为「年费滞纳」，提示 6 个月滞纳期内补缴，逾期权利终止 |
| 商标续展 | 专用权期满前 395 天内提醒，续展窗口为期满前 12 个月，宽展期 6 个月 |
| 商标撤三 | 核准注册满 3 年且状态有效，提示补充使用证据或删减未使用项目 |
| 数据知识产权 | 登记有效期 2 年，30 天内到期为高、90 天内为中，已过期为高 |
| 审查周期 | 发明审查超 30 个月、实用新型与外观超 12 个月提示核查程序性瑕疵 |
| 提实审期限 | 发明专利申请中且距申请日起满 24 个月，提示 3 年内提出实审请求 |

保护期限默认口径：发明 20 年、实用新型 10 年、外观设计 15 年（均自申请日起算）；软件著作权与作品著作权 50 年；注册商标 10 年可续展；数据知识产权登记有效期 2 年可续展。

## 八、技术栈

- **后端**：Python 3 标准库（`http.server` + `sqlite3` + `json`），零第三方依赖
- **前端**：原生 HTML / CSS / JavaScript，单页应用 + Hash 路由
- **图表**：ECharts 5.5（本地化部署，无外网依赖）
- **存储**：SQLite，单文件持久化

## 九、常见问题

**Q：刷新页面后数据会丢失吗？**
不会。数据写入服务端 SQLite 文件，刷新、重启浏览器或重启服务后数据均保留。

**Q：端口被占用怎么办？**
换端口启动：`python server.py 9000`。

**Q：如何录入本企业真实数据？**
直接在「知识产权管理」页新建；或在「系统设置」页清空全部数据后逐条录入，同时修改企业信息。演示数据可随时一键恢复。

**Q：换电脑如何迁移？**
在「系统设置」页导出 JSON 备份，在新机器启动系统后导入；或复制整个项目目录（含 `data/ipms.db`）。
